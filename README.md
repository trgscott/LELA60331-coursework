# LELA60331-coursework
An NLP System for the classification of product reviews - assigning helpfulness ratings.
This project contains the following sections of code which need to be run sequentially, so you can run all. If you would like to skip to section 11, sections 1 and 2 still need running first. There is in-code annotation to help describe the processes.
1. Loading the data and libraries
2. Top down tokenisation
3. Create one-hot encodings
4. Split the data into training/development/test sets
5. Softmax regression using one-hot encodings and L2 regularization
6. Softmax interpretation - one-hot encodings and L2
7. Softmax regression - Test set evaluation
8. Neural network model using one-hot encodings
9. Neural network - interpretation
10. Neural network - Test set evaluation
11. Word2Vec embeddings
12. Softmax regression using Word2Vec embeddings, L2
13. Softmax with Word2Vec and L2 - Test set evaluation

Appendix - error finding code, does not need to be run.
